# VK parser для поиска групп студентов под рекламу StudyAssist

Скрипт собирает публичные сообщества ВКонтакте и ранжирует их по релевантности аудитории студентов для запуска рекламы сайта **studyassist.ru** (помощь в учебных и выпускных работах, консалтинг).

## Что делает

- Ищет группы по нескольким запросам через `groups.search`.
- Подтягивает расширенные поля группы через `groups.getById`.
- Оценивает активность по постам за период (по умолчанию 90 дней) через `wall.get`.
- Считает score релевантности на основе:
  - размера аудитории;
  - ключевых слов в названии/описании/деятельности;
  - регулярности публикаций;
  - исключающих признаков нерелевантной аудитории.
- Сохраняет результаты в `CSV` и `JSON`.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Подготовка

1. Получите токен доступа VK API (service/user token) с правами чтения групп и стены.
2. Установите токен в переменную окружения:

```bash
export VK_TOKEN='ваш_токен'
```

## Запуск

```bash
python3 parser_vk_groups.py \
  --queries "студенты,курсовая работа,дипломная работа,вуз,университет" \
  --max-groups 300 \
  --min-members 700 \
  --max-members 300000 \
  --min-score 5.5 \
  --output vk_groups_students.csv \
  --json-output vk_groups_students.json
```

## Рекомендации для вашей кампании VK Ads

- Создайте 2-3 сегмента по intent:
  - «Курсовые/рефераты»;
  - «Диплом/ВКР»;
  - «Экзамены/сессия/дедлайны».
- В креативах делайте акцент на:
  - экспертный консалтинг;
  - помощь со структурой и методологией;
  - сопровождение до защиты.
- Исключайте явно школьные паблики и аудиторию абитуриентов.
- Используйте look-alike на основе лидов с сайта studyassist.ru после первых конверсий.

## Важные замечания

- Соблюдайте правила VK и законодательство по обработке персональных данных.
- Не парсите закрытые сообщества и не собирайте персональные данные пользователей.
- Скрипт работает только с публичными данными сообществ.
